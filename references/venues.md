# 分学科顶会顶刊参考清单

**用途**：判断文献综述是否覆盖了本学科公认的高水平成果。只看"够不够、是不是本学科的"，不评价具体论文质量。

**重要说明**

- 各校研究生院多有**自己的 A/B/C 类期刊目录**，以学院认定为准；本清单只是通用参考。
- 清单会过时（新会议、分区调整），不要当成权威目录引用。
- 中文期刊在各学科的权重差异极大：计算机类偏英文会议，人文社科、教育学、医学临床则大量依赖中文权威期刊。**不要拿计算机的标准去判别人的综述**。

## 计算机 / 人工智能

| 方向 | 顶级会议 | 顶级期刊 |
|---|---|---|
| 机器学习 | NeurIPS, ICML, ICLR | JMLR, TPAMI |
| 计算机视觉 | CVPR, ICCV, ECCV | TPAMI, IJCV, TIP |
| 自然语言处理 | ACL, EMNLP, NAACL | TACL, Computational Linguistics |
| 数据挖掘/数据库 | KDD, SIGMOD, VLDB, ICDE | TKDE, VLDBJ |
| 系统/网络 | OSDI, SOSP, NSDI, SIGCOMM | TOCS, TON |
| 安全 | CCS, IEEE S&P, USENIX Security, NDSS | TDSC |

| 软件工程 | ICSE, FSE, ASE | TSE, TOSEM |

**硕士论文的现实口径**：综述里有 3–5 篇近 3 年本方向顶会，且能说清"它们还差在哪"，通常就够了。要求"全顶会"不现实。

## 怎么用这份清单给分

1. 先确认论文属于哪个学科（看题目、摘要、目标期刊/会议）。
2. 抽查综述中近 5 年文献的发表载体：本学科顶会顶刊占比多少？
3. 按档判断：
   - 有 3 篇以上近 3 年本学科顶会顶刊，且被批判性讨论 → 90 档
   - 有顶刊但只是罗列、无批判 → 75 档
   - 全是低水平会议/灌水期刊，或漏掉最相关的同题工作 → 60 档
4. 不确定学科归属时，**不要扣分**，在「待确认清单」里问用户"贵院认定的高水平期刊目录是哪个"。
