# 送审前保密与合规检查

**每次评审开始前，先向用户提一次。**只用一段话，不要长篇大论，但不要跳过。

## 三个必问

### 1. 论文是否已经送审？

已经进入盲审流程的论文，外传给第三方大模型可能构成**违规**（多数学校的盲审保密承诺书明确禁止向第三方披露评审材料）。如果已送审，建议停止上传，只做本地脱敏后自查。

### 2. 是否涉及保密内容？

以下情形风险最高：

- 军工、国防相关项目
- 企业横向合作、未公开的工艺参数、产线数据
- 已申请但未公开的专利技术方案
- 涉密单位的名称、项目编号、内部标准

只要命中一条，**不要整篇上传**。改为只上传"方法章 + 实验设计"的脱敏片段。

### 3. 学校是否允许使用 AI 辅助？

越来越多的高校出台了 AI 使用规定（有的要求声明，有的禁止上传论文原文）。不清楚就按"不允许"处理。

## 脱敏清单（上传前逐项删）

- [ ] 作者姓名、学号
- [ ] 导师姓名
- [ ] 学校/学院/实验室名称（含页眉页脚、致谢）
- [ ] 基金项目编号、横向合同号
- [ ] 致谢中的合作单位与人名
- [ ] 专利号、软著号（未公开的）
- [ ] 内部数据表的表头单位名
- [ ] PDF 元数据（作者、机构、创建软件）——很多人忘了这一层

## 建议做法

| 场景 | 建议 |
|---|---|
| 只是想知道"结构上有什么问题" | 只上传目录 + 摘要 + 章节摘要，不上传全文 |
| 要查方法问题 | 上传方法章 + 实验章（脱敏后） |
| 要查格式问题 | 本地跑 Word/LaTeX 检查，不需要上传 |
| 确实需要全文评审 | 用本地部署模型（Ollama / vLLM + 开源权重），或学校提供的私有化服务 |

## 评审后

- 删除对话记录与上传的临时文件（多数平台的"删除会话"并不立即清除服务端日志，重要材料不要图省事）
- 保留一份"我用了 AI 自查"的操作记录，答辩时若被问到可以说明

## 给模型的固定提醒语

在输出开头写一句：

> 提示：本评审基于上传内容生成，仅供参考。论文内含保密信息时请勿上传第三方服务；已送审的论文请遵守学校盲审保密规定。
